# Диагностика

Через Win+R откройте %USERPROFILE%\.reqtest\logs (либо каталог REQTEST_LOG_DIR).

- extraction-diagnostics-…json — выделение обязательств.
- coverage-diagnostics-…json — анализ покрытия.

Для текущей проблемы повторите только пару SDD_MVA_INIT_F_00040::E001 / TC_CRC_001. Пришлите самый новый coverage-diagnostics-…json. В нём запросы, исходные ответы, реально присутствовавшие поля, проверка цитат и итоговые статусы. Ключи и параметры соединения не экспортируются. Известный ключ маскируется. Тексты ваших требований и тестов сохраняются.

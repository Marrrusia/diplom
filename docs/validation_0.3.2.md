условий при классификации, индексы, роли, отмена, SQLite и журнал. Технический
прогон подменённого корпуса: 12/12 операций; это не оценка качества модели.

- IRQ: 57,406 с, два запроса. Фронт и запись счётчика выделены, но «before
  acknowledging the interrupt» ошибочно стало самостоятельным действием.
- STATE: 28,812 с, два запроса. Действия выделены, условия режимов потеряны.
  Оба предложения заблокированы проверкой отсутствующей метки ветви.

вместо самостоятельного действия. Проверен отдельным тестом; новый запуск модели
после этой локальной проверки не выполнялся, запрос модели не изменился.

Разделение этапов реализовано. Улучшение семантического качества на этой модели
не доказано. Сохраняются ручная проверка и неподтверждённая полнота. Это версия
для дальнейших испытаний. Пользовательский проект и модель не изменялись.

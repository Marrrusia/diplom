# Проверки 0.3.3 — 21 октября 2026

232 проверки кода проходят. Подмена корпуса: 12/12 операций, не оценка качества.
Проверены исправление черновых ролей, частичный ответ, отсутствие всех валидных
строк, отмена, HTTP двух провайдеров, хранение/экспорт журнала и границы литералов.

Настоящая модель: существующая qwen2.5:7b, Ollama, CPU, настройки не менялись.
Эталоны в запросы не передавались. Прогнаны три требования, для которых 0.3.2
не завершала новое выделение. После изменения механизма 3/3 операции завершились
частичным результатом. Это устойчивость обработки, а не правильность выделения.

| Требование | Секунды | Сохранено | Проблемы |
| --- | ---: | ---: | --- |
| MODE | 170.953 | 1 | Целое предложение ошибочно названо условием; две строки исключены из-за склеенных цитат условий |
| MASK | 116.860 | 3 | Второй этап по-прежнему оставил ожидаемые эффекты в условиях и потерял общий вызов |
| AMBIG | 64.000 | 1 | Непроверяемое «быстро» осталось действием, заблокировано; ещё одна строка исключена из-за неверной цитаты |

Всего шесть запросов, 351.813 с. Ответы review слишком сильно повторяют черновик;
улучшение семантического качества не доказано. После прогона добавлен сигнал
ручной проверки требуемого поведения («должен/shall/must») в применимости или
описании условия. Он проверен тестом; новый запуск модели после этой локальной
проверки не выполнялся, поскольку сами запросы к модели не менялись.

Версия исправляет частичное сохранение, свободу исправления ролей и ложное
предупреждение PollSensor/PollSensor(). Дальнейшее качество выделения требует
отдельной работы и ручной оценки на разнообразном корпусе. Сырые ответы модели
в локальном отчёте остаются неизменёнными.

# Исправление отказа выделения DEMO_MODE_002

По сообщению пользователя исправлены ложные ошибки полноты: русские слова в
цитатах сравниваются без различения регистра, повторные упоминания одного режима
не создают несколько обязательных аспектов. Регистр технических имён сохраняется.
Предложение, сообщающее только об отсутствии спецификации, не создаёт обязательный
режим. Смешанный источник с явно заданным обязательным действием не исключается.

Если модель выбрала одновременно источники заданного поведения и отдельный
источник пробела спецификации, для проверки элемента используются источники
заданного поведения. Фраза о пробеле сохраняется в замечаниях автоматически.
Один лишь источник неопределённого поведения не подтверждает проверяемое действие.
При ошибке модель получает уточнение, какие source_ids выбрать и куда вынести пробел.

Добавлены 6 проверок, включая демонстрационное требование, технический регистр,
смешанный источник и отказ выдуманному действию. Полный набор: 212 проверок.
Настоящий ответ пользовательской модели неизвестен: на скриншоте видна диагностика,
поэтому воспроизведены причины отказа, а не точный JSON ответа сервера.

После обновления проекта повторите выделение элементов. Поведение ACTIVE при
ADC_READY != 1 должно оставаться замечанием о недостаточности спецификации.

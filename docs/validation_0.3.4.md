# Проверки 0.3.4

237 автоматических проверок проходят. Проверена передача параметров для обоих
провайдеров: прежняя температура 0 либо наследование настроек сервера. Для Ollama
проверены think=false и отсутствие принудительного think при выборе по умолчанию.
Главное окно с новыми переключателями открывается/закрывается в offscreen-режиме.

Qwen3.5-9B Q5_K_M от Unsloth загружена с Hugging Face. Размер 6577841376 байт,
SHA256 dc2a39aef291f91a9116ad214058da0d86eb648743a124bd8c333787c4b9c91c
сверен с метаданными репозитория. Модель зарегистрирована в Ollama 0.40.4 как
qwen35-9b-q5. Старые веса qwen2.5:7b сохранены.

Простой HTTP-тест с think=false вернул {"ok":true}, 14.437 с, включая первый
запуск. Подтверждены Q5_K_M и параметры профиля: temperature 0.7, top_p 0.8,
top_k 20, num_ctx 8192, presence_penalty 1.5, min_p 0, repeat_penalty 1.
Этот тест проверяет соединение и формат ответа, а не качество выделения.

Настоящий разбор MODE с настройками сервера и think=false занял 226.187 с
за два этапа. Получено пять элементов, но возврат STATUS_NOT_READY ошибочно
назван условием (помечен программой). Для части действий контекст остался
в описании вместо отдельной применимости, общий вызов не всегда сохранён.
Признать качество равным облачной модели по этому тесту нельзя. Сырые ответы
сохранены в отдельном локальном qwen35-mode-check.json.

Добавлено поле времени ожидания (по умолчанию 180 с, допускается 30–1800 с).
Для CPU-проверок новой модели рекомендовано начать с 600 с на один запрос.

Приложение поставляется отдельным архивом. Пользовательская папка проекта
не перезаписывалась. Настройки модели выбираются пользователем в текущем сеансе.

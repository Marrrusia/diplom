# Проверки 0.3.6 — 22 октября 2026

251 автоматизированный тест прошёл на Windows 11 / Python 3.12.14.
Проверены источники и позиции, связи ветвей, отрицательные условия, безопасное
разделение действий, ошибочные ID, частичные ответы, сохранение SQLite,
диагностика, интерфейс и полный сценарий импорта, анализа и экспорта.
Первый финальный запуск остановился на создании временных каталогов pytest;
повторный запуск с новым каталогом внутри рабочего пространства прошёл полностью.

Реальный прогон: локальная Ollama, qwen35-9b-q5:latest, настройки модели по
умолчанию, thinking=false, тайм-аут 600 секунд. Пять требований, один запрос
на каждое, все операции завершились. Суммарное время около 312 секунд.
Эталоны не передавались модели. Это небольшая качественная проверка,
не измерение точности на представительной выборке.

| Требование | Наблюдение | Время, с |
|---|---|---:|
| Диапазон SetLevel | Четыре результата, две ветви условий | 89.829 |
| Режимы ReadSample | Пять результатов; условие ADC_READY связано с чтением и возвратом | 91.531 |
| Неопределённая спецификация | Элементов нет, перечислены пробелы | 22.922 |
| Новый ACCESS_OK / иначе | Четыре результата, отрицательные связи для ветви иначе | 49.984 |
| Новый английский VALID | Четыре результата, две отдельные ветви | 58.031 |

Остались неточности: сохранение неизменности currentLevel и buffer модель
классифицировала как действие; в ReadSample есть пересекающиеся условия STANDBY,
а общий вызов ReadSample не связан отдельно со всеми действиями ACTIVE.
Успешное завершение операции не означает подтверждённую полноту или покрытие.

В предварительном прогоне модель пропускала необязательные поля условий
и называла некоторые результаты условиями. После этого все пять полей
сделаны обязательными в передаваемой JSON-схеме, добавлено короткое различие
между предпосылкой и возвратом значения. Таблица относится к повторному прогону.
Последующее локальное предупреждение о непривязанных условиях из описания
проверено тестами; дополнительные запросы к модели после него не выполнялись.

Старый предоставленный проект: одно требование, восемь элементов, шесть тестов,
48 связей покрытия. Все связи ожидали проверки, подтверждённых покрытий нет.
Открытие и сохранение копии проверены; исходная база не изменена.
В прежнем анализе покрытия замечены смысловые ошибки. Эта версия обновляет
выделение элементов; исправление всех ошибок покрытия не заявляется.

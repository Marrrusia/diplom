# Настройки локальной модели

В 0.3.4 в разделе настроек LLM появились:

- «Параметры генерации»: прежняя температура 0 либо настройки модели на сервере.
- «Рассуждения (Ollama)»: по умолчанию, выключены или включены.

В 0.3.5 начальные значения UI уже соответствуют установленной qwen35-9b-q5:latest:
настройки сервера, выключенные рассуждения и ожидание 600 секунд. Для первого теста модели
qwen35-9b-q5 выберите настройки модели на сервере и выключенные рассуждения.
Адрес http://localhost:11434, API-ключ пустой. Модель импортируется отдельно;
архив исходников не содержит её веса. Настройки существуют только в сеансе.

Modelfile профиля задаёт num_ctx 8192, temperature 0.7, top_p 0.8, top_k 20,
min_p 0, presence_penalty 1.5 и repeat_penalty 1. Это стартовый профиль для
испытаний, а не подтверждённый оптимум для анализа требований. При выборе
«Настройки модели на сервере» приложение не перекрывает параметры профиля.
В OpenAI-совместимом режиме переключатель рассуждений не передаётся.

Использование большего контекста и включение рассуждений могут увеличить расход
памяти и время ответа. По умолчанию ожидание одного запроса 180 секунд;
для первого теста на CPU задайте в поле «Ожидание ответа, с» значение 600.
Корректность модели проверяйте на том же наборе требований и новых примерах;
настройка соединения не является доказательством качества анализа.

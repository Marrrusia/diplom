# Упрощение 0.3.5

Вместо черновика и повторного переписывания выполняется один запрос на требование.
Инструкция содержит только задачу, независимость аспектов, условия ветви,
буквальную цитату, точные имена/числа, категории и недостаточность спецификации.
Демонстрационные примеры и длинный перечень исправлений удалены.

Ответ: elements с type, description, source_fragment, applicability и отдельный
specification_gaps. Применимость — текст, а не граф ссылок. При корректной структуре
и источниках второго запроса нет. Ошибки структуры/цитат допускают до трёх попыток;
при неизменной ошибке цитаты сохраняется лучшая валидная часть с диагностикой.
Повтор не является самостоятельной семантической экспертизой.

Сохраняются Pydantic, проверка цитат, локальные признаки сомнений и исходные ответы.
Полнота всегда неподтверждённая до ручной проверки. Проверка имён описания теперь
учитывает цитату и текст применимости; имена применимости отдельно сверяются
с исходным требованием. Это не доказательство правильности выбора ветви.

Двухэтапный модуль удалён. Исторические журналы obligations/review и старые проекты
по-прежнему читаются, новые ответы имеют stage=direct. Проверки удалённого процесса
заменены проверками публичного одноэтапного пути, старые проверки цитат/сборки
снова вызывают публичную функцию. Тесты не оценивают качество реальной модели.

Для этого локального проекта начальные настройки UI установлены на уже имеющуюся
qwen35-9b-q5:latest, настройки модели сервера, рассуждения выключены, ожидание 600 с.
Можно выбрать любую другую модель. Весов в архиве исходников нет.

# Доработка 0.3.1

Уточнён общий запрос выделения: критерий проверяемости, независимые эффекты,
отсутствие спецификации, диапазоны и буквальное копирование цитат.

Добавлены консервативные сигналы ручной проверки для русских и английских
формулировок. Составные эффекты, качественные критерии без чисел, сообщения
о неопределённости и диапазоны без явных границ помечаются analysis_blocked.
Предложения сохраняются; автоматическое разрезание или переписывание не выполняется.
После явного подтверждения пользователем элемент может участвовать в анализе.

Это эвристики, а не семантический доказатель: они могут пропускать ошибки
и помечать корректные фразы. Условие с логическим И, перечисление аргументов,
отрицание вызова и символические границы проверены на отсутствие блокировки.
Неподтверждённая полнота требований сохраняется независимо от числа пометок.

209 автоматических проверок проходят. При повторной проверке сохранённых
ответов из extraction-diagnostics.json помечены 8 предложений из 22 с найденными
цитатами. Ещё один кандидат имеет отсутствующую цитату и не восстановлен.
Это повторная проверка старых ответов, а не новый запуск модели. Новый запрос
на настоящей модели не проверен: доступ к локальному серверу ограничен средой.
Ошибки модели исправленными не объявляются. Изменение поставлено отдельным
архивом; пользовательская папка проекта и настройки модели не изменялись.

# Ограничения и корректная интерпретация

- 100% относится к активным выделенным элементам и принятым связям. Это не
  гарантия полноты требований, правильности реализации или успешного выполнения тестов.
- Реальная модель может пропустить факт, неверно истолковать цитату или предложить
  ошибочный сценарий. Проверка структуры и наличия цитаты не доказывает смысл.
- Уверенность LLM не калибрована как вероятность. Порог 0.8 — эвристика.
- Противоречия и полнота детерминированно проверяются только для поддерживаемых
  формулировок; произвольный естественный язык не проверяется формально.
- Тесты привязаны к одному requirement_id. В этой версии межтребовательное
  покрытие и тест с несколькими ID требований не поддерживаются.
- DOCX/TXT должны соответствовать документированному формату. Сложные таблицы,
  сканы, PDF и произвольная разметка не распознаются универсально.
- Большая матрица требует много запросов: сумма элементов × активных тестов
  по каждому требованию. Нет пакетной оптимизации и автоматического ограничения
  размера больших проектов; используйте разумные наборы для ВКР.
- Первоначальная генерация не гарантирует один тест или полный набор. Пропуски
  отражаются в журнале; покрытие подтверждается отдельно.
- Отмена не прерывает уже выполняющийся HTTP-запрос мгновенно. Его время
  ограничено таймаутом; медленная локальная модель может потребовать повторного запроса.
- Исходный процент старого проекта без снимка неизвестен. При изменении основания
  сравнения снимок сбрасывается; сравнение разных наборов элементов не подделывается.
- Отклонённые элементы исключены из знаменателя и показываются отдельным счётчиком.
  Их отклонение нельзя считать доказательством полноты.
- SQLite хранит текущий снимок и журнал генерации, а не аудит каждой редакции.
  Нет автосохранения и совместного редактирования несколькими пользователями.
- API-ключ в файлы проекта не записывается; постоянного хранилища ключей нет.
  Документы при работе с внешним сервером передаются этому серверу по выбранному адресу.
- Qt и автоматические проверки проверены в облачной Linux-среде. Сессия пользователя
  показала работу интерфейса на Windows, но это не заменяет формального протокола
  испытаний каждой конфигурации. GitHub Actions подготовлен, запуск не подтверждён.
